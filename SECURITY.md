# Security

Report a vulnerability privately through GitHub: **Security > Report a vulnerability** on this
repository. Please do not open a public issue for it.

In scope: the workflows, the audit PR content guard, the pnpm and Biome settings, and anything that lets
a pull request reach `main` without passing the gates. A vulnerability in a third-party package belongs
with that package; this repo picks up the fix through the automation it documents.
